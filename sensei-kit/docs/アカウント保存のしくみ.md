# アカウントに保存（鍵つき）のしくみと、本番のつなぎ方

ジーニー会員のアカウントでログインすると、どの端末でも同じ内容を使える。中身は先生の端末で暗号にしてから送るので、**運営（サーバー）は中身を読めない**。

## しくみ

| 所 | 何が置かれるか |
|---|---|
| 先生の端末 | 写し（localStorage の `sensei:u:<アカウント>:`。いままでどおり画面はここを読み書き）／鍵（IndexedDB。取り出せない形）／ログインの記録（`sensei:cloud:session`） |
| 会員サイトの Supabase（スキーマ `sensei`） | `vaults`＝合言葉の確かめ用（salt・回数・決まった文字を暗号にしたもの）／`blobs`＝道具の記録 1件ずつの暗号（AES-GCM）／`settings`＝上限など |

- 鍵：合言葉 → PBKDF2（SHA-256・60万回・salt 16バイト）→ AES-GCM 256。合言葉も鍵もサーバーに送らない。
- 1件ずつ、置き場所（種類・名前・ID）を「追加の認証データ」に入れて暗号にする（サーバー側で行を入れかえても開けない）。
- 送る：写しに書くたびに「送るもの」に入れ、1.2秒後にまとめて `sensei.push`（最大 200 行・3MB）。電波がないときは、つながってから。
- 受け取る：開いたとき・画面に戻ったとき・1分ごとに `sensei.pull`（前回から5秒さかのぼって、変わった行だけ）。まだ送っていない、この端末の変更を残す。
- 同時に直したら、あとから送った方が残る。消したものは「消した印」を120日残して、ほかの端末からも消す。
- 合言葉を忘れたら：運営も戻せない。写しが残っている端末で「作り直す」（新しい合言葉で、写しを入れ直す）。ほかの端末は、次に開いたとき新しい合言葉を聞く。
- ログアウト：鍵とログインの記録を消す。「この端末の写しも消す」（共用パソコン向け・最初から選ばれている）。
- 使える人：会員サイトにプロフィールがあり、利用停止でない人（`sensei._me()`）。保護者会アプリの人は使えない。プランで絞るときは `update sensei.settings set min_rank = 20;`（ギルド以上 など）。
- 上限：1人 10MB・6000 行、sensei 全体 200MB（会員サイトと容量を分け合うため。`sensei.settings` で変えられる）。
- デモ（使い方）は砂場で動き、アカウントには何も送らない。

## 本番のつなぎ方（kazu が行う）

1. `supabase/本番に入れる.command` をダブルクリック → SQL Editor に貼って Run（結果：tables=3・rls_all_on=true・anon_functions=0）
2. Settings → API（Data API）の Exposed schemas に `sensei` を**追加**して Save
3. Claude が公開用キーだけで確かめる（未ログインは断られる・関数が見える）→ `config.js` の `cloud` を `true` にして公開

やめるとき：Exposed schemas から `sensei` を外す → `supabase/teardown.sql`（順番を逆にすると会員サイトの API ごと止まる）。

## 確かめたこと（2026-10-20）

- 会員サイトの複製（supabase-safety-check：会員サイトの SQL を本番の順に流したもの）に `sensei.sql` を流して：既存の表・列・制約・索引・トリガー・ポリシー・関数・権限の**変更 0**（増えたのは sensei の中の 51 行だけ）／2回流しても通る／未ログイン・無料・ギルド・管理者の4人の見え方 172 マスが前後で完全に同じ／teardown で指紋が流す前と完全に一致。
- 入口：未ログインは呼べない・会員（無料・ギルド・管理者）は呼べる・プロフィールのない人（保護者会アプリの人）と利用停止の人は断る・min_rank でプランを絞れる・表は直接読めない・退会（アカウントの削除）を止めず、その人の行も消える。
- 手元の Supabase（`tools/cloud-local.sh`）と2台の端末にみたてたブラウザで（`tools/cloud-test.cjs`。Chrome と WebKit）：ログイン・パスワードちがい・合言葉を決める・この端末のデータを入れる・サーバーには暗号だけ（名前・メモ・JSON の手がかりが読めない）・2台目は合言葉ちがいを断る・名簿が届く・足す／消すが両方に届く・電波なしは未送信で残りつながったら送る・デモはアカウントに何も送らない・ログアウトで写しと鍵が消える・作り直し（写しで入れ直す）・古い合言葉は通らない・β版はログインした会員だけ。

## 確かめていないこと

- 本番そのもの（流したあと、公開用キーだけで確かめる）。本物の iPhone・iPad の Safari、学校の共用パソコン（ブラウザの保存が終了時に消える設定）。
- 2台でまったく同時に同じものを直したときの細かい順番（あとから送った方が残る作り）。
