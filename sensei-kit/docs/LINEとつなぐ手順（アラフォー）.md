# 先生の道具箱を「アラフォー」公式LINE の特典にする：LINE Developers の設定手順

公式LINE「アラフォーキャリアに悩む教員向け人生相談」から、先生の道具箱を **LIFF**（LINE の中で開くページ）で開けるようにする。
LIFF で開くと、LINE が「本人確認の札（ID トークン）」をページに渡し、サーバーで本物か確かめてから、**だれがどの道具を使ったか**を記録する（生徒の名前や入力した中身は送らない）。

所要：約10分。パソコンで行う（スマホのアプリには、この画面はない）。

## 1. プロバイダーを開く

1. https://developers.line.biz/console/ に、アラフォーの公式LINE の管理者の LINE アカウントでログイン。
2. **アラフォーの公式LINE の Messaging API を有効にしたときのプロバイダー**（2026-10-07 に作ったもの）を開く。
   - 必ず同じプロバイダーに作る。LINE の「利用者を見分ける番号（ユーザーID）」はプロバイダーごとにちがうので、別のプロバイダーだと、line-hub の友だち（タグ・属性）と突き合わせられない。プロバイダーは後から移せない。

## 2. 「LINE ログイン」のチャネルを作る

1. 「新規チャネル作成」→「**LINE ログイン**」。
2. 入れるもの：
   - 会社・事業者の所在国・地域：日本
   - チャネル名：例「先生の道具箱」（LINE の同意画面に出る）
   - チャネル説明：例「アラフォーの先生向けの特典ツール」
   - アプリタイプ：**ウェブアプリ**
   - メールアドレス：運営の連絡先
   - プライバシーポリシー URL：あとで入れてよい（友だちに配る前＝「公開済み」にする前には必要。下の 5）
3. 「LINE開発者契約」に同意して「作成」。（同意は kazu が押す）

## 3. LIFF を追加する

作ったチャネルの「**LIFF**」タブ →「追加」：
- LIFF アプリ名：先生の道具箱
- サイズ：**Full**
- エンドポイント URL：`https://dora9991.github.io/gazou-prompt/sensei-kit/`（**最後の / まで正確に**）
- Scope：**openid** と **profile** にチェック（chat_message.write は不要）
- 友だち追加オプション：**On (normal)** がおすすめ（同意画面で、アラフォーの公式LINE の友だち追加をすすめる）
  - 選べないときは、「チャネル基本設定」の「**リンクされたLINE公式アカウント**」でアラフォーの公式LINE を選んでから。
- Scan QR・モジュールモード：オフのまま

## 4. Claude に伝えるもの（どちらも秘密の値ではない）

- **LIFF ID**（LIFF タブに出る。例 `1234567890-AbCdEfGh`）
- **チャネル ID**（「チャネル基本設定」の数字）

**チャネルシークレットは使わないので、送らない・どこにも貼らない。**

## 5. 公開する前に

- 作った直後は「**開発中**」＝管理者とテスターだけが開ける。kazu のスマホで確かめるのはこのままでよい。
- 友だちに配る前に：プライバシーポリシーに一文を足し（例「公式LINE から先生の道具箱を開くと、LINE の表示名と、どの道具を使ったかを記録します。生徒の名前や入力した内容は記録しません」）、その URL をチャネルに入れて「**公開済み**」にする。**公開済みから開発中には戻せない。**
- 配るリンクは `https://liff.line.me/<LIFF ID>`（リッチメニュー・キーワードの返事・配信に使う）。

## 6. 記録の置き場所を入れる（会員サイトの Supabase・kazu の作業・約10分）

1. `supabase/LINEの記録を入れる.command` をダブルクリック。
   - ① SQL（スキーマ sensei_usage）を SQL Editor に貼って Run → いちばん下の「管理キー（su_…）」を控える（利用状況の画面で使う）
   - ② Exposed schemas に `sensei_usage` を追加（いまある名前は消さない）
   - ③ チャネル ID を入れると、LINE の本人確認の関数（sensei-line）と設定を自動で入れる
2. Claude に「入れた」と LIFF ID を伝える → Claude が公開用キーだけで確かめ、`config.js` の `line` に LIFF ID を入れて公開し直す。
3. 自分のスマホで `https://liff.line.me/<LIFF ID>` を開く → 同意 → ホームの「データの扱い」に「LINE（自分の名前）から開いたので…」と出れば完成。
   利用状況は `https://dora9991.github.io/gazou-prompt/sensei-kit/usage-admin.html`（管理キーで開く）。

## 7. line-hub の「その人専用のリンク」でも配る（任意）

line-hub の管理画面の「リンク」で、次のリンクを1つ作る：
- 行き先の URL：`https://dora9991.github.io/gazou-prompt/sensei-kit/`
- 行き先に付ける記号（ref_param）：`c`（押した人ごとに `?c=lh-…` が付く）
- タグ：例「見た:先生の道具箱」
キーワードの返事や配信の文に `{{link:キー}}` と書くと、その人専用のリンクになる。押した人がだれかは line-hub の「押した人」、どの道具を使ったかは利用状況の画面の「リンク lh-…」で分かる。

## アプリを直したとき（LINE 側の作業はいらない）

- LIFF は「このページを開く」という入口だけを持っている。道具箱を直して公開し直せば、LIFF のリンクはそのままで、次に開いた人から新しい版になる（反映まで数分。LINE の中のブラウザが少しのあいだ前の版を覚えていることがある）。
- LINE 側の作業が要るのは、置き場所の URL を変えたとき・Scope を変えたとき・LIFF を作り直したときだけ。
