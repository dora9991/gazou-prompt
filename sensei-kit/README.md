# 先生の道具箱（sensei-kit）

学級・授業・予定の「ちょっとした困りごと」を、1つの名簿でつないだ道具一式。ブラウザだけで動き、サーバーは使わない。
名簿を1回入れると、席替え・係決め・当番表・宿題の提出チェックがそのまま使える。行事の予定とリマインダー・宿題の締切は、カレンダーとホームに集まり、学級通信の予定表や連絡の文にも入れられる。

**▶ アプリを開く：https://dora9991.github.io/gazou-prompt/sensei-kit/**

最初は、架空のクラス「2年3組」と架空の学校の例で全部が動いている。ホームの「自分のクラスで始める」で、自分のクラスに切りかえる。

土台（`js/kit.js`・`css/kit.css`）は、みせびらき（math-dialogue の `startup-kit/`）を写して、色と看板を学校向けにしたもの。アプリの書き方・保存のしかたが同じなので、道具を行き来させられる。

## 開き方

| どこで | どうする | 保存先 |
|---|---|---|
| 手元のパソコン・スマホ | `sensei-kit-all-in-one.html` をダウンロードして、ダブルクリック（1ファイルで全部入り） | そのブラウザ（localStorage） |
| フォルダごと | `index.html` をブラウザで開く（ビルドもサーバーも要らない） | そのブラウザ |
| Web に置く | フォルダごと GitHub Pages・Cloudflare Pages などに置く（共有リンクが使えるようになる） | 開いた人のブラウザ |
| Claude の Artifact | `node tools/bundle.cjs --artifact` でできる `dist/artifact.html` を公開する | 持ち主のアカウント（端末をまたいで同じ内容） |

> ブラウザに保存しているときは、ブラウザのデータを消すと消える。ホームの「バックアップを書き出す」で、ときどき JSON に書き出しておく（「バックアップから戻す」で戻せる）。

## 共有のしくみ（サーバーなし）

- 予定・リマインダー・わたしの時間割は「共有リンク」か「共有用のファイル（.json）」で渡せる。リンクの `#share=…` に中身を縮めて入れているので、サーバーに何も残らない（# より後ろはサーバーに送られない）。
- 受け取った人は、中身を確かめてから自分の道具箱に取り込む（リンクを開くと取り込みの画面が出る。ファイルはホームの「共有ファイルを開く」から）。
- 共有には生徒の名前を入れない（予定・リマインダー・時間割だけ）。
- そのときの内容を写して渡すしくみなので、あとで直しても相手は変わらない。学年で同じ予定をずっと見たいときは、学年の Googleカレンダーをつくって .ics を取り込むのが確実。
- 先生どうしの「ずっと同じものを見る」共有・生徒や保護者との連絡・宿題の配布と提出は、サーバーが要る。数学ポータルに足す案は [docs/つなぐ機能の設計.md](docs/つなぐ機能の設計.md)。

## データの扱い（大事）

- 名簿・席・係・当番・宿題の記録・通信・わたしのひな形は、このブラウザの中だけに保存する。外へは送らない。
- 学級通信の写真は、小さくしてこのブラウザに保存する（1枚 200KB ほど）。たくさん入れると保存の場所がいっぱいになるので、古い号の写真は消しておく。生徒が写った写真は、学校の決まり（掲載の同意など）を確かめてから使う。
- 名簿は出席番号だけでも使える。教室で画面を映すときは、クラスの帯の「名前を隠す」を使う（席・係・宿題は番号だけになり、名簿はぼかす）。
- 学校の共用パソコンでは、使い終えたらバックアップを書き出して「すべて消して最初から」を押す。
- Web に置くときは、同じドメインのほかのページからブラウザの保存場所が見える（GitHub Pages の `ユーザー名.github.io` は全部同じドメイン）。知らないページを同じ場所に置かない。

### 道具を足す・直すときの約束

- 1道具＝`js/apps/<id>.js` の `Kit.app({ id, title, group, icon, mount(root, params) })` ひとつ。`index.html` に `<script>` を1行足す。group は `class`（クラス）・`lesson`（授業）・`plan`（予定）・`write`（通信・連絡）。
- 保存は `Kit.store` だけを使う（手元では localStorage、Artifact では db に自動で切りかわる）。ひとつもの は `get/set`、ならぶもの は `list/put/remove`。
- クラスに結びつく記録は `classId` を持たせ、`School.classes.onRemove(School.removeByClass('<coll>'))` でクラスを消したときに一緒に消す。
- 生徒の名前を出すところは `School.label(生徒)` を使う（「名前を隠す」に従う）。
- 解く部品（くじ・組み合わせ）は `js/core/` に、画面から切りはなして書き、`tools/test.cjs` で確かめる。
- 直したら：`node tools/test.cjs` → `node tools/check.cjs --fresh` → `node tools/flow.cjs` → `node tools/bundle.cjs`。

## 確かめたこと

- `tools/test.cjs`：390 件（席替え 4つの男女の並び × 5回で、全員着席・前の席・はなす2人・空席は後ろ・前回と同じとなりなし／時間割 6〜12クラス・先生1人6クラスまで、毎回すべて入り、先生の重なり・都合・同じ日の2回なし・固定のコマ・2時間続き／係決め 定員をこえない・全員1つ・当たりは希望者から／当番表 班の人数と男女の差は1人まで・席の近い人で・掃除はどの班もどの場所も1回ずつ・回転盤と同じ向き・休みの班・お休みの週・2週ごと・給食の役割のずらし・日直は休みの日をとばす／和暦（令和元年・平成31年）・時候・差し込み・19のひな形がすべてうまる／Word の部品・ZIP の CRC・2段の区切り・B4・写真・記号の書きかえ・どの XML も正しく読める／祝日 2026〜2027年は みせびらき の表と一致・2019・2020 の特別な年／名簿の読み取り4形式／共有リンクの往復／年間行事の読み取り／ICS の往復と知らせ）
