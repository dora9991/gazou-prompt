# 先生の道具箱（sensei-kit）

学級・授業・予定の「ちょっとした困りごと」を、1つの名簿でつないだ道具一式。ブラウザだけで動く。ログインしなければサーバーは使わない（ジーニー会員でログインすると、鍵をかけてアカウントにも保存できる）。
名簿を1回入れると、席替え・係決め・当番表・宿題の提出チェックがそのまま使える。行事の予定とリマインダー・宿題の締切は、カレンダーとホームに集まり、学級通信の予定表や連絡の文にも入れられる。

**▶ アプリを開く：https://dora9991.github.io/gazou-prompt/sensei-kit/**

最初は、架空のクラス「2年3組」と架空の学校の例で全部が動いている。ホームの「自分のクラスで始める」で、自分のクラスに切りかえる。

**使い方のデモ**：どの道具も、見出しの横の「▶ 使い方を見る」で、操作の流れを実際に動かして見せる（光る囲み・吹き出し・動く指。「次へ」「やってみる」で1手ずつ、「自動で」で最後まで）。デモのあいだは架空のクラスの砂場で動き、上に「デモ中」の帯が出る。**本物のデータは読まず・書かない**（「デモを終わる」かページの読み込み直しで元に戻る）。自分のクラスに切りかえたあとでも、いつでも見られる。

土台（`js/kit.js`・`css/kit.css`）は、みせびらき（math-dialogue の `startup-kit/`）を写して、色と看板を学校向けにしたもの。アプリの書き方・保存のしかたが同じなので、道具を行き来させられる。

## 開き方

| どこで | どうする | 保存先 |
|---|---|---|
| 手元のパソコン・スマホ | `sensei-kit-all-in-one.html` をダウンロードして、ダブルクリック（1ファイルで全部入り） | そのブラウザ（localStorage） |
| フォルダごと | `index.html` をブラウザで開く（ビルドもサーバーも要らない） | そのブラウザ |
| Web に置く | フォルダごと GitHub Pages・Cloudflare Pages などに置く（共有リンクが使えるようになる） | 開いた人のブラウザ |
| Claude の Artifact | `node tools/bundle.cjs --artifact` でできる `dist/artifact.html` を公開する | 持ち主のアカウント（端末をまたいで同じ内容） |

> ブラウザに保存しているときは、ブラウザのデータを消すと消える。ホームの「バックアップを書き出す」で、ときどき JSON に書き出しておく（「バックアップから戻す」で戻せる）。

## 使い方のデモのしくみ（`js/demo.js`・`js/tours/*.js`）

- `Kit.demo.start(id)` で、`Kit.store` を砂場（メモリ）に、`Kit.pref` をメモリだけに切りかえてから道具を開き直し、`Kit.tour(id, 手順)` の手順を出す。`Kit.demo.end()` で本物の保存先に戻して開き直す。
- 手順の書き方は `js/demo.js` の先頭。1道具＝`js/tours/<id>.js` 1つ。手順の文は「です・ます」、1つ 70 字くらいまで。
- ダウンロード・印刷・コピー・ファイル選び・通知の許可は、デモでは押さない（場所を見せるだけ）。
- 確かめ：`node tools/demo-check.cjs`（全道具のデモを最後まで進め、どの手順も囲む所が見つかるか・エラーがないか・終えたあと本物のデータが1文字も変わっていないか・本物のクラスに戻るかを、Chrome と WebKit × パソコンとスマホで）。

## アカウントに保存（鍵つき）

- ジーニー会員のアカウントでログインすると、どの端末でも同じ内容を使える。保存先は会員サイトの Supabase の専用スキーマ `sensei`（会員サイトの表には何もさわらない）。
- 中身は先生の端末で、先生が決めた「合言葉」から作った鍵で暗号にしてから送る。**サーバー（運営）は中身を読めない。** 合言葉を忘れると、ほかの端末では開けない（写しが残っている端末で「作り直す」）。
- ログインしなければ、いままでどおり「この端末だけ」に保存。2つは混ざらない。
- しくみ・本番のつなぎ方・確かめたことは [docs/アカウント保存のしくみ.md](docs/アカウント保存のしくみ.md)。`config.js` の `cloud` が `true` のときだけ、ログインの入口が出る。
- 確かめ：`./tools/cloud-local.sh`（手元の Supabase を起こす）→ `node tools/cloud-test.cjs`（Chrome と WebKit。2台の端末にみたてる）→ `./tools/cloud-local.sh --stop`。

## β版（会員限定）

- 成績（かんたん成績）・面談の日程（面談スケジューラ）・動画編集（おまかせ動画エディタの Web 版 `beta/video/`）を、ログインした会員にだけメニューとホームに出す（`js/apps/beta.js`）。
- 「会員限定」は画面の上でのしぼり込み。アプリ本体の URL は公開の置き場所にあるので、URL を知っていれば開ける。有料にするときは、本体を会員だけが取り出せる置き場所（会員サイトのストレージの署名つき URL など）に移す。
- β版の道具のデータは、それぞれのアプリの中（その端末のブラウザ）に保存され、アカウントには入らない。

## 公式LINE「アラフォー」の特典として（利用の記録・LIFF）

- 公式LINE から開いた人だけ、**どの道具で何をしたか**（例：席替え／席替えをした、チラシ／印刷）を記録する（`js/usage.js`）。生徒の名前・名簿・入力した中身は送らない。ホームの「データの扱い」に説明と「記録を止める」が出る。
- だれの記録か：LIFF（`https://liff.line.me/<LIFF ID>`）から開くと、Edge Function `sensei-line` が LINE に本人確認をして札を出す（LINE の表示名）。line-hub の「その人専用のリンク」から開くと `?c=lh-…`（コード）。どちらもないときは何も送らない。
- LINE の中で開いたときは「ブラウザで開く」で、1回だけ使える受け渡しの札（10分）をつけて Safari・Chrome に開き直せる（LINE の中のブラウザは保存が消えやすいため）。
- 置き場所：会員サイトの Supabase の専用スキーマ `sensei_usage`（`supabase/sensei_usage.sql`。会員サイトの表には何もさわらない）。利用状況は `usage-admin.html`（管理キー）。
- 本番のつなぎ方：[docs/LINEとつなぐ手順（アラフォー）.md](docs/LINEとつなぐ手順（アラフォー）.md)（LINE Developers → `supabase/LINEの記録を入れる.command` → `config.js` の `line` に LIFF ID）。
- 確かめ：`./tools/cloud-local.sh` → `node tools/usage-test.cjs`（サーバー26件＋Chrome・WebKit 各15件）。会員サイトの複製で既存の変更 0・見え方 172 マス一致・やめる SQL で指紋一致（2026-10-20）。

## 共有のしくみ（サーバーなし）

- 予定・リマインダー・わたしの時間割は「共有リンク」か「共有用のファイル（.json）」で渡せる。リンクの `#share=…` に中身を縮めて入れているので、サーバーに何も残らない（# より後ろはサーバーに送られない）。
- 受け取った人は、中身を確かめてから自分の道具箱に取り込む（リンクを開くと取り込みの画面が出る。ファイルはホームの「共有ファイルを開く」から）。
- 共有には生徒の名前を入れない（予定・リマインダー・時間割だけ）。
- そのときの内容を写して渡すしくみなので、あとで直しても相手は変わらない。学年で同じ予定をずっと見たいときは、学年の Googleカレンダーをつくって .ics を取り込むのが確実。
- 先生どうしの「ずっと同じものを見る」共有・生徒や保護者との連絡・宿題の配布と提出は、サーバーが要る。数学ポータルに足す案は [docs/つなぐ機能の設計.md](docs/つなぐ機能の設計.md)。

## データの扱い（大事）

- 名簿・席・係・当番・宿題の記録・通信・わたしのひな形は、ログインしていなければ、このブラウザの中だけに保存する。外へは送らない。ログインしているときは、端末で鍵をかけた暗号だけをアカウントに送る（運営は読めない）。
- 学級通信の写真は、小さくしてこのブラウザに保存する（1枚 200KB ほど）。たくさん入れると保存の場所がいっぱいになるので、古い号の写真は消しておく。生徒が写った写真は、学校の決まり（掲載の同意など）を確かめてから使う。
- 名簿は出席番号だけでも使える。教室で画面を映すときは、クラスの帯の「名前を隠す」を使う（席・係・宿題は番号だけになり、名簿はぼかす）。
- 学校の共用パソコンでは、使い終えたらバックアップを書き出して「すべて消して最初から」を押す。
- Web に置くときは、同じドメインのほかのページからブラウザの保存場所が見える（GitHub Pages の `ユーザー名.github.io` は全部同じドメイン）。知らないページを同じ場所に置かない。

### 道具を足す・直すときの約束

- 1道具＝`js/apps/<id>.js` の `Kit.app({ id, title, group, icon, mount(root, params) })` ひとつ。`index.html` に `<script>` を1行足す。group は `class`（クラス）・`lesson`（授業）・`plan`（予定）・`write`（通信・連絡）。
- 保存は `Kit.store` だけを使う（手元では localStorage、Artifact では db に自動で切りかわる）。ひとつもの は `get/set`、ならぶもの は `list/put/remove`。
- クラスに結びつく記録は `classId` を持たせ、`School.classes.onRemove(School.removeByClass('<coll>'))` でクラスを消したときに一緒に消す。
- 生徒の名前を出すところは `School.label(生徒)` を使う（「名前を隠す」に従う）。
